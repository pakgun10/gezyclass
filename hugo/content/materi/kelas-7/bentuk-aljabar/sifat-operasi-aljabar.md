## Tujuan Pembelajaran

Setelah mempelajari subbab ini, murid diharapkan mampu:

1. **Mengidentifikasi** sifat komutatif, asosiatif, dan distributif pada operasi bentuk aljabar
2. **Menggunakan** sifat-sifat operasi untuk menyederhanakan bentuk aljabar
3. **Menerapkan** sifat distributif untuk mengalikan bentuk aljabar

---

## A. Sifat Komutatif (Pertukaran)

Sifat komutatif berlaku pada penjumlahan dan perkalian: urutan tidak mengubah hasil.

$$a + b = b + a$$
$$a \times b = b \times a$$

### Contoh 1

$3x + 5x = 5x + 3x = 8x$ dan $2 \times 3x = 3x \times 2 = 6x$

> Sifat komutatif **tidak berlaku** untuk pengurangan dan pembagian: $a - b \neq b - a$.

---

## B. Sifat Asosiatif (Pengelompokan)

Sifat asosiatif berlaku pada penjumlahan dan perkalian: cara mengelompokkan tidak mengubah hasil.

$$(a + b) + c = a + (b + c)$$
$$(a \times b) \times c = a \times (b \times c)$$

### Contoh 2

$(2x + 3x) + 4x = 2x + (3x + 4x) = 9x$

$(2 \times 3x) \times 4 = 2 \times (3x \times 4) = 24x$

---

## C. Sifat Distributif (Penyebaran)

Sifat distributif menghubungkan perkalian dengan penjumlahan/pengurangan.

$$a(b + c) = ab + ac$$
$$a(b - c) = ab - ac$$

![Sifat distributif: a(b+c) = ab+ac](/images/aljabar-distributif.png)

### Contoh 3

Sederhanakan $3(x + 2)$!

**Jawab:** $3(x + 2) = 3x + 6$

### Contoh 4

Sederhanakan $2(3a - 5)$!

**Jawab:** $2(3a - 5) = 6a - 10$

### Contoh 5

Sederhanakan $-2(x - 4)$!

**Jawab:** $-2(x - 4) = -2x + 8$ (ingat: negatif kali negatif = positif)

---

## D. Rangkuman

| Sifat | Penjumlahan | Perkalian |
|:------|:------------|:----------|
| Komutatif | $a + b = b + a$ | $a \times b = b \times a$ |
| Asosiatif | $(a+b)+c = a+(b+c)$ | $(a \times b) \times c = a \times (b \times c)$ |
| Distributif | — | $a(b+c) = ab+ac$ |

<div class="note">
💡 <strong>Tips:</strong> Sifat distributif adalah kunci untuk menghilangkan tanda kurung. Gambar ubin aljabar membantu melihat mengapa $a(b+c) = ab+ac$.
</div>

## E. Latihan Soal

1. Tentukan hasil dari $4(x + 3)$!
2. Tentukan hasil dari $-3(2y - 1)$!
3. Sederhanakan $(3x + 2) + (5x + 7)$ dengan sifat asosiatif!
4. Tentukan hasil dari $x(2x + 3)$!
5. Gunakan sifat distributif untuk menghitung $6 \times 104$ (tulis $104$ sebagai $100 + 4$)!
6. Sederhanakan $2(a + b) + 3(a - b)$!

---

1. $4x + 12$
2. $-6y + 3$

4. $2x^2 + 3x$
5. $6(100 + 4) = 600 + 24 = 624$
6. $2a + 2b + 3a - 3b = 5a - b$
