## Tujuan Pembelajaran

Setelah mempelajari materi ini, siswa diharapkan mampu:

1. **Menjumlahkan** dua bilangan rasional dalam bentuk pecahan
2. **Menjumlahkan** dua bilangan rasional dalam bentuk desimal
3. **Mengurangkan** dua bilangan rasional
4. **Menyelesaikan** masalah operasi campuran penjumlahan dan pengurangan bilangan rasional

---

## A. Penjumlahan Pecahan

### Syarat: Penyebut Harus Sama

$$\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}$$

### Jika Penyebut Berbeda

$$\frac{a}{b} + \frac{c}{d} = \frac{a \times d + c \times b}{b \times d}$$

### Contoh 1: Penjumlahan Pecahan

| Soal | Penyelesaian | Hasil |
|:---:|:------------:|:-----:|
| $\frac{2}{7} + \frac{3}{7}$ | $\frac{2+3}{7}$ | $\frac{5}{7}$ |
| $\frac{1}{4} + \frac{2}{4}$ | $\frac{1+2}{4} = \frac{3}{4}$ | $\frac{3}{4}$ |
| $\frac{1}{3} + \frac{1}{4}$ | $\frac{1\times4 + 1\times3}{12} = \frac{7}{12}$ | $\frac{7}{12}$ |
| $\frac{2}{5} + \frac{3}{8}$ | $\frac{2\times8 + 3\times5}{40} = \frac{31}{40}$ | $\frac{31}{40}$ |
| $\frac{3}{4} + \frac{5}{6}$ | $\frac{3\times6 + 5\times4}{24} = \frac{38}{24} = \frac{19}{12}$ | $1\frac{7}{12}$ |
| $1\frac{1}{2} + 2\frac{1}{3}$ | $\frac{3}{2} + \frac{7}{3} = \frac{9+14}{6} = \frac{23}{6}$ | $3\frac{5}{6}$ |

### Contoh 2: Penjumlahan Pecahan Campuran

$$2\frac{1}{3} + 1\frac{3}{5} = \frac{7}{3} + \frac{8}{5} = \frac{35 + 24}{15} = \frac{59}{15} = 3\frac{14}{15}$$

**Atau dengan cara pisah:**
$$2\frac{1}{3} + 1\frac{3}{5} = (2+1) + \left(\frac{1}{3} + \frac{3}{5}\right) = 3 + \frac{5+9}{15} = 3 + \frac{14}{15} = 3\frac{14}{15}$$

## B. Pengurangan Pecahan

### Sama dengan Penjumlahan, tapi Dikurang

$$\frac{a}{c} - \frac{b}{c} = \frac{a - b}{c}$$

$$\frac{a}{b} - \frac{c}{d} = \frac{a \times d - c \times b}{b \times d}$$

### Contoh 3: Pengurangan Pecahan

| Soal | Penyelesaian | Hasil |
|:---:|:------------:|:-----:|
| $\frac{5}{8} - \frac{2}{8}$ | $\frac{5-2}{8}$ | $\frac{3}{8}$ |
| $\frac{3}{4} - \frac{1}{6}$ | $\frac{3\times6 - 1\times4}{24} = \frac{14}{24}$ | $\frac{7}{12}$ |
| $\frac{7}{9} - \frac{2}{5}$ | $\frac{7\times5 - 2\times9}{45} = \frac{17}{45}$ | $\frac{17}{45}$ |
| $2\frac{1}{2} - 1\frac{1}{3}$ | $\frac{5}{2} - \frac{4}{3} = \frac{15-8}{6} = \frac{7}{6}$ | $1\frac{1}{6}$ |
| $\frac{5}{6} - \frac{3}{4}$ | $\frac{5\times4 - 3\times6}{24} = \frac{20-18}{24}$ | $\frac{1}{12}$ |

## C. Penjumlahan dan Pengurangan Desimal

### Aturan: Luruskan Komanya

$$\begin{aligned}
3,25 + 1,7 &= 3,25 + 1,70 = 4,95 \\
5,8 - 2,35 &= 5,80 - 2,35 = 3,45 \\
12,4 + 0,625 &= 12,400 + 0,625 = 13,025 \\
7,5 - 3,125 &= 7,500 - 3,125 = 4,375
\end{aligned}$$

### Contoh 4: Campuran

| Soal | Penyelesaian | Hasil |
|:---:|:------------:|:-----:|
| $2,5 + 3,75$ | $2,50 + 3,75$ | $6,25$ |
| $8,4 - 2,6$ | $8,4 - 2,6$ | $5,8$ |
| $12,05 + 3,8$ | $12,05 + 3,80$ | $15,85$ |
| $10 - 4,25$ | $10,00 - 4,25$ | $5,75$ |
| $0,75 + 0,125$ | $0,750 + 0,125$ | $0,875$ |

---

## D. Operasi Campuran (Pecahan + Desimal)

### Contoh 5: Campuran Pecahan dan Desimal

Ubah ke bentuk yang sama (pecahan atau desimal), lalu hitung.

$$0,5 + \frac{1}{3} = \frac{1}{2} + \frac{1}{3} = \frac{3+2}{6} = \frac{5}{6}$$

$$\frac{3}{4} - 0,25 = 0,75 - 0,25 = 0,5$$

$$1,2 + \frac{2}{5} = 1,2 + 0,4 = 1,6$$

## E. Rangkuman

| No | Operasi | Cara |
|:--:|:-------:|:-----|
| 1 | **Pecahan sama penyebut** | Jumlah/kurang pembilang |
| 2 | **Pecahan beda penyebut** | Samakan penyebut (KPK) |
| 3 | **Pecahan campuran** | Ubah ke pecahan biasa dulu |
| 4 | **Desimal** | Luruskan koma |
| 5 | **Campuran** | Ubah ke bentuk yang sama |

<div class="note">
💡 <strong>Tips:</strong> Untuk pecahan beda penyebut, gunakan KPK untuk mencari penyebut yang sama. Atau gunakan cara cepat: $\frac{a}{b} \pm \frac{c}{d} = \frac{a\times d \pm c\times b}{b\times d}$
</div>

## G. Kunci Jawaban

1. $\frac{2}{5} + \frac{1}{4} = \frac{8+5}{20} = \frac{13}{20}$

7. $7,5 - 2,25 = 5,25$
8. $\frac{1}{2} + 0,75 = 0,5 + 0,75 = 1,25$
9. $1,25 - \frac{1}{4} = 1,25 - 0,25 = 1$
