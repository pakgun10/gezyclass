## Tujuan Pembelajaran

Setelah mempelajari materi ini, siswa diharapkan mampu:

1. **Menjumlahkan** dua bilangan bulat (positif dan negatif)
2. **Mengurangkan** dua bilangan bulat
3. **Menerapkan** konsep $a - b = a + (-b)$
4. **Menyelesaikan** masalah sehari-hari tentang penjumlahan dan pengurangan bilangan bulat

---

## A. Penjumlahan Bilangan Bulat

### Penjumlahan dengan Garis Bilangan

Untuk menjumlahkan bilangan bulat, kita bisa menggunakan garis bilangan:
- Bergerak ke **kanan** untuk bilangan **positif**
- Bergerak ke **kiri** untuk bilangan **negatif**

### Contoh 1: Berbagai Tipe Penjumlahan

| Soal | Proses pada Garis Bilangan | Hasil |
|:---:|:--------------------------:|:-----:|
| $3 + 5$ | Mulai di $3$, ke kanan $5$ langkah | $8$ |
| $(-2) + (-4)$ | Mulai di $-2$, ke kiri $4$ langkah | $-6$ |
| $6 + (-3)$ | Mulai di $6$, ke kiri $3$ langkah | $3$ |
| $(-5) + 8$ | Mulai di $-5$, ke kanan $8$ langkah | $3$ |
| $(-7) + 3$ | Mulai di $-7$, ke kanan $3$ langkah | $-4$ |
| $4 + (-9)$ | Mulai di $4$, ke kiri $9$ langkah | $-5$ |

### Aturan Praktis Penjumlahan

| Jenis | Aturan | Contoh |
|:----:|:------:|:------:|
| **Sama tanda** (positif + positif) | Jumlahkan, tandanya positif | $4 + 7 = 11$ |
| **Sama tanda** (negatif + negatif) | Jumlahkan, tandanya negatif | $(-3) + (-6) = -9$ |
| **Beda tanda** | Cari selisih, ikuti tanda bilangan yang lebih besar | $8 + (-3) = 5$ |
| **Beda tanda** | Cari selisih, ikuti tanda bilangan yang lebih besar | $(-7) + 4 = -3$ |

> 💡 **Tips:** Utang $5$ ditambah utang $3$ = utang $8$, jadi $(-5) + (-3) = -8$. Punya $10$ tapi utang $7$ = punya $3$, jadi $10 + (-7) = 3$.

## B. Pengurangan Bilangan Bulat

### Konsep Dasar

Mengurangkan bilangan bulat sama dengan **menjumlahkan dengan lawan bilangan**:

$$\boxed{a - b = a + (-b)}$$

### Contoh 2: Mengubah Pengurangan ke Penjumlahan

| Soal | Ubah ke Penjumlahan | Hasil |
|:---:|:-------------------:|:-----:|
| $8 - 3$ | $8 + (-3)$ | $5$ |
| $5 - 9$ | $5 + (-9)$ | $-4$ |
| $(-6) - 2$ | $(-6) + (-2)$ | $-8$ |
| $(-4) - (-7)$ | $(-4) + 7$ | $3$ |
| $3 - (-5)$ | $3 + 5$ | $8$ |
| $(-2) - (-8)$ | $(-2) + 8$ | $6$ |

### Aturan Praktis Pengurangan

| Jenis | Aturan | Contoh |
|:----:|:------:|:------:|
| $a - b$ (b positif) | Sama dengan $a + (-b)$ | $7 - 4 = 7 + (-4) = 3$ |
| $a - (-b)$ | Sama dengan $a + b$ | $7 - (-4) = 7 + 4 = 11$ |
| $(-a) - b$ | Sama dengan $(-a) + (-b)$ | $(-7) - 4 = (-7) + (-4) = -11$ |
| $(-a) - (-b)$ | Sama dengan $(-a) + b$ | $(-7) - (-4) = (-7) + 4 = -3$ |

## C. Contoh Soal Cerita

### Contoh 3: Suhu

Suhu di kota Tokyo pada pagi hari $-3^{\circ}C$. Pada siang hari suhu naik $7^{\circ}C$. Berapa suhu pada siang hari?

**Penyelesaian:**

$$(-3) + 7 = 4$$

Jadi, suhu pada siang hari adalah $\mathbf{4^{\circ}C}$.

### Contoh 4: Utang dan Tabungan

Andi memiliki uang Rp10.000. Ia membeli buku seharga Rp15.000. Berapa utang Andi sekarang?

**Penyelesaian:**

$$10.000 - 15.000 = -5.000$$

Jadi, Andi memiliki utang sebesar **Rp5.000**.

### Contoh 5: Kedalaman

Seorang penyelam berada di kedalaman $-12$ meter. Ia naik $5$ meter. Berapa posisinya sekarang?

$$(-12) + 5 = -7$$

Jadi, penyelam berada di kedalaman $\mathbf{-7}$ meter.

## D. Rangkuman

| No | Operasi | Aturan |
|:--:|:-------:|:-------|
| 1 | **Sama tanda** | Jumlahkan, tanda tetap |
| 2 | **Beda tanda** | Kurangkan, ikuti tanda bilangan besar |
| 3 | **Pengurangan** | $a - b = a + (-b)$ |
| 4 | **Kurang negatif** | $a - (-b) = a + b$ |

<div class="note">
💡 <strong>Tips Kunci:</strong> <strong>Kurang negatif = tambah positif.</strong> Hafalkan ini: $5 - (-3) = 5 + 3 = 8$.
</div>
