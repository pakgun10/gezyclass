## Tujuan Pembelajaran

Setelah mempelajari subbab ini, murid diharapkan mampu:

1. **Menentukan** nilai fungsi dengan notasi $f(x)$
2. **Menghitung** nilai fungsi untuk nilai $x$ tertentu
3. **Menentukan** rumus fungsi dari data yang diberikan

---

## A. Notasi Fungsi

Fungsi linear ditulis:

$$f(x) = ax + b$$

dengan $a$ dan $b$ konstanta. Untuk menentukan nilai fungsi pada $x = c$, substitusikan $c$ ke dalam rumus: $f(c) = ac + b$.

---

## B. Contoh Soal

### Contoh 1: Menghitung Nilai Fungsi

Diketahui $f(x) = 2x + 3$. Tentukan $f(4)$ dan $f(-1)$!

**Jawab:**

- $f(4) = 2(4) + 3 = 8 + 3 = 11$
- $f(-1) = 2(-1) + 3 = -2 + 3 = 1$

### Contoh 2: Mencari Nilai $x$

Diketahui $f(x) = 3x - 5$. Jika $f(a) = 16$, tentukan nilai $a$!

**Jawab:**

$$3a - 5 = 16 \Rightarrow 3a = 21 \Rightarrow a = 7$$

### Contoh 3: Menentukan Rumus Fungsi

Diketahui $f(1) = 5$ dan $f(2) = 7$. Tentukan rumus fungsi $f(x)$!

**Jawab:** Misal $f(x) = ax + b$.

- $f(1) = a + b = 5$ ... (1)
- $f(2) = 2a + b = 7$ ... (2)

Kurangkan (2) − (1): $a = 2$. Substitusi ke (1): $2 + b = 5 \Rightarrow b = 3$.

Jadi $f(x) = 2x + 3$.

---

<div class="note">
💡 <strong>Tips:</strong> Untuk menemukan rumus fungsi dari dua titik, susun dua persamaan lalu selesaikan dengan eliminasi/substitusi — persis seperti SPLDV.
</div>

---

## C. Latihan Soal

1. $f(x) = 4x - 1$. Tentukan $f(3)$!
2. $f(x) = x^2 + 2$. Tentukan $f(5)$!
3. $f(x) = 2x + 7$. Jika $f(k) = 23$, tentukan $k$!
4. Diketahui $f(2) = 9$ dan $f(3) = 13$. Tentukan rumus $f(x)$!
5. $f(x) = 5 - 3x$. Tentukan $f(-2)$!
6. Diketahui $f(x) = ax + b$ dengan $f(0) = 4$ dan $f(1) = 7$. Tentukan $a$ dan $b$!

---

## D. Kunci Jawaban

1. $f(3) = 4(3) - 1 = 11$
2. $f(5) = 25 + 2 = 27$
3. $2k + 7 = 23 \Rightarrow k = 8$
4. $a + b = 9$; $3a + b = 13$ (perhatikan $f(2) = 2a+b$): $2a+b=9$, $3a+b=13$ $\Rightarrow a=4$, $b=1$; $f(x) = 4x + 1$
5. $f(-2) = 5 - 3(-2) = 5 + 6 = 11$
6. $f(0)=b=4$; $a+4=7 \Rightarrow a=3$; jadi $f(x)=3x+4$
