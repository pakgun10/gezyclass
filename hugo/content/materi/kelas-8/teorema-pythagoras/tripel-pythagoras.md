## A. Pengertian Tripel Pythagoras

Tripel Pythagoras adalah **tiga bilangan bulat positif** $(a, b, c)$ yang memenuhi $a^2 + b^2 = c^2$.

### Tripel Dasar

| $(a, b, c)$ | Periksa | Keterangan |
|:-----------:|:-------:|:-----------|
| $(3, 4, 5)$ | $9 + 16 = 25$ ✅ | Paling terkenal |
| $(5, 12, 13)$ | $25 + 144 = 169$ ✅ | Sering muncul |
| $(7, 24, 25)$ | $49 + 576 = 625$ ✅ | |
| $(8, 15, 17)$ | $64 + 225 = 289$ ✅ | |
| $(9, 40, 41)$ | $81 + 1600 = 1681$ ✅ | |
| $(11, 60, 61)$ | $121 + 3600 = 3721$ ✅ | |

---

## B. Kelipatan Tripel Pythagoras

Jika $(a, b, c)$ tripel Pythagoras, maka $(ka, kb, kc)$ untuk $k$ bulat positif juga tripel Pythagoras.

| Kelipatan | Tripel | $a^2 + b^2$ | $c^2$ |
|:---------:|:------:|:-----------:|:-----:|
| $k=1$ | $(3, 4, 5)$ | $9 + 16 = 25$ | $25$ |
| $k=2$ | $(6, 8, 10)$ | $36 + 64 = 100$ | $100$ |
| $k=3$ | $(9, 12, 15)$ | $81 + 144 = 225$ | $225$ |
| $k=4$ | $(12, 16, 20)$ | $144 + 256 = 400$ | $400$ |
| $k=5$ | $(15, 20, 25)$ | $225 + 400 = 625$ | $625$ |

> **Pola:** $(3,4,5)$ jika dikali $k$, hasilnya $(3k, 4k, 5k)$.

---

## C. Cara Membuat Tripel Pythagoras

### Rumus Tripel Pythagoras

Untuk bilangan bulat $m > n > 0$:

$$a = m^2 - n^2$$
$$b = 2mn$$
$$c = m^2 + n^2$$

### Contoh

Ambil $m = 2$, $n = 1$:
- $a = 4 - 1 = 3$
- $b = 2 \times 2 \times 1 = 4$
- $c = 4 + 1 = 5$
- Tripel: $(3, 4, 5)$ ✅

Ambil $m = 3$, $n = 2$:
- $a = 9 - 4 = 5$
- $b = 2 \times 3 \times 2 = 12$
- $c = 9 + 4 = 13$
- Tripel: $(5, 12, 13)$ ✅

## E. Latihan Soal

1. Apakah $(5, 12, 13)$ tripel Pythagoras? Buktikan!
2. Tentukan tripel yang merupakan kelipatan 3 dari $(3, 4, 5)$!
3. Apakah $(9, 12, 15)$ tripel Pythagoras?
4. Tentukan tripel dari $m = 4$, $n = 1$!
5. Apakah $(8, 10, 12)$ tripel Pythagoras?
6. Mana yang bukan tripel: $(6,8,10)$, $(10,24,26)$, $(12,13,15)$?
7. Jika $a = 3k$, $b = 4k$, $c = 5k$ dengan $k=7$, hitung sisi-sisinya!
8. Tentukan tripel Pythagoras dari $m=5$, $n=2$!

## F. Kunci Jawaban

1. $5^2 + 12^2 = 25 + 144 = 169 = 13^2$. Ya! ✅
2. $(9, 12, 15)$
3. $9^2 + 12^2 = 81 + 144 = 225 = 15^2$. Ya! ✅
