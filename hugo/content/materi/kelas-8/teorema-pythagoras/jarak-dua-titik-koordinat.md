## Tujuan Pembelajaran

Setelah mempelajari materi ini, siswa diharapkan mampu:

1. **Menentukan** selisih koordinat $x$ dan $y$ dua titik
2. **Menghitung** jarak dua titik menggunakan rumus $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$
3. **Menyelesaikan** masalah kontekstual terkait jarak pada koordinat

---

## A. Rumus Jarak Dua Titik

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

Ini berasal dari teorema Pythagoras:
- $\Delta x = x_2 - x_1$ (selisih horizontal)
- $\Delta y = y_2 - y_1$ (selisih vertikal)

---

## B. Contoh

### Contoh 1: Titik Sederhana

Titik $A(1, 2)$ dan $B(5, 5)$. Hitung jaraknya!

$\Delta x = 5 - 1 = 4$
$\Delta y = 5 - 2 = 3$
$d = \sqrt{4^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = 5$

### Contoh 2: Dengan Negatif

$P(-2, 3)$ dan $Q(4, -1)$.

$\Delta x = 4 - (-2) = 6$
$\Delta y = -1 - 3 = -4$
$d = \sqrt{6^2 + (-4)^2} = \sqrt{36 + 16} = \sqrt{52} = 2\sqrt{13}$

---

## D. Rangkuman

$\text{Jarak} = \sqrt{(\text{selisih }x)^2 + (\text{selisih }y)^2}$

<div class="note">
💡 <strong>Tips:</strong> Selisih bisa positif atau negatif — kuadratkan selalu hasil positif. Urutan titik tidak penting: $\sqrt{(x_2-x_1)^2+(y_2-y_1)^2} = \sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$.
</div>

## E. Latihan Soal

1. $A(1,1)$, $B(4,5)$. Hitung jarak!
2. $P(-3,2)$, $Q(2,14)$. Hitung jarak!
3. $C(0,0)$, $D(7,24)$. Hitung jarak!
4. Jarak $(2,3)$ ke $(x,7) = 5$. Tentukan $x$!
5. Buktikan titik $(0,0)$, $(6,8)$, $(12,0)$ membentuk segitiga sama kaki!
6. Jarak rumah Andi $(2,3)$ ke sekolah $(8,11)$. Berapa km (dalam satuan kotak)?

---

## F. Kunci Jawaban

1. $d = \sqrt{3^2+4^2} = 5$
2. $d = \sqrt{5^2+12^2} = 13$
3. $d = \sqrt{7^2+24^2} = 25$
4. $\sqrt{(x-2)^2 + (7-3)^2} = 5 \Rightarrow (x-2)^2 + 16 = 25 \Rightarrow (x-2)^2 = 9 \Rightarrow x-2 = \pm3 \Rightarrow x = 5 \text{ atau } x = -1$
5. $d(0,0)\text{ ke }(6,8) = 10$, $d(6,8)\text{ ke }(12,0) = \sqrt{6^2+8^2} = 10$, $d(0,0)\text{ ke }(12,0) = 12$. Dua sisi sama = segitiga sama kaki.
6. $d = \sqrt{6^2+8^2} = 10$ satuan kotak
